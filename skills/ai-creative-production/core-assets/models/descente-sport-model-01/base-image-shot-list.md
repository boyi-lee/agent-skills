# DESCENTE SPORT Model D / DV1 Base Image Shot List

DV1 is the canonical identity reference for Model D (Naomi Lin / 林梵耘).

## Required canonical views

1. Front portrait
   - neutral expression
   - natural skin texture
   - hair pulled back or low ponytail
   - clean daylight

2. 3/4 portrait
   - slight head turn
   - preserve jawline, eye spacing, nose and lip proportions

3. Full body
   - upright relaxed posture
   - visible shoulder / waist / hip / leg proportions
   - neutral athletic styling

4. Side profile / over-shoulder
   - preserve face depth and profile
   - natural neck and shoulder line

5. Outdoor standing lifestyle
   - relaxed functional styling
   - natural daylight
   - no exaggerated fashion posing

6. Outdoor seated / lifestyle
   - relaxed believable posture
   - maintain the same facial identity and body ratio

## Identity lock rules

Every new DV1 image must keep:
- the same face identity
- the same body proportion family
- 168–170 cm height impression
- slim, balanced athletic build
- dark brown / black hair family
- natural realistic skin texture
- clean, cool, low-aggression presence

Reject an image if the model looks like a different person, if body proportions change enough to affect garment-fit interpretation, or if the rendering looks obviously synthetic / plastic.

## Purpose

These base views are not channel outputs. They are reference assets used by downstream generation and review skills to keep DV1 stable across different SKUs, scenes and channels.
