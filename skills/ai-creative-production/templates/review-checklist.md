# Review Checklist

## Product Fidelity
- [ ] 顏色與 Landing Page 一致
- [ ] Logo 正確且位置合理
- [ ] 版型與剪裁一致
- [ ] 領口 / 袖口 / 褲型一致
- [ ] 拼接、圖案、車線等關鍵細節無明顯錯誤
- [ ] 無 AI 自行新增不存在的設計

重大錯誤：任一關鍵商品特徵錯誤 → `FAIL`

## Model Consistency
- [ ] 臉仍為指定 Model
- [ ] 身形比例一致
- [ ] 髮型與主要外觀特徵無明顯漂移
- [ ] 手、臉、四肢無異常
- [ ] 未過度接近原真人參考身份

## Creative Quality
- [ ] 場景符合 Scene Card
- [ ] 光影自然
- [ ] 人物與環境融合自然
- [ ] 構圖可作為廣告素材
- [ ] 尺寸 / 比例正確

## Decision
- `PASS`: 三層皆可接受，可進人工 Final Gate
- `CHECK`: 無重大商品錯誤，但存在需要人判斷的問題
- `FAIL`: 商品錯誤、Model 嚴重漂移、人體異常或素材不可商用
