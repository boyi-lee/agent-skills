# Skill: Channel LINE

## Purpose
把已通過 Quality Review 的素材轉成 LINE OA / LINE Ads 可用版本。

## Input
- approved asset
- product asset
- campaign message
- line placement spec

## Output
- LINE OA image variants
- rich message / rich menu visual variants（如適用）
- LINE Ads crop / ratio variants
- export manifest

## Must Do
- 依 LINE 版位優先處理手機閱讀性與安全區。
- 保留商品主體清楚可辨識。
- 所有版本回指 approved source asset。

## Must Not Do
- 不得自行修改商品外觀。
- 不得自行創造優惠或商品功能。

## Validation
需通過手機可讀性、版位安全區、商品一致性與輸出規格檢查。
