# Skill: Channel Web

## Purpose
把已通過 Quality Review 的素材整理成官網 / PDP / Lookbook 可用版本。

## Input
- approved asset
- product asset
- styling plan
- page placement spec

## Output
- PDP hero
- full-body look
- half-body / detail look
- lookbook variants
- crop / ratio manifest

## Must Do
- 優先支援商品理解與購買決策。
- 必須保留商品細節可辨識性。
- 可依版位裁切，但不得改 Product Identity。

## Must Not Do
- 不可自行重新生成另一件「類似」商品。
- 不可把低解析或 review 未通過素材當正式官網素材。

## Validation
需通過 Web placement、crop、detail visibility 與商品一致性檢查。
