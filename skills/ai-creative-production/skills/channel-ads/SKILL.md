# Skill: Channel Ads

## Purpose
把已通過 Quality Review 的素材轉成 Meta Ads / Google Ads 所需素材變體。

## Input
- approved asset
- product asset
- styling plan
- campaign objective / target signal
- platform spec

## Output
- Meta ratios / variants
- Google / PMax ratios / variants
- creative signal mapping
- export manifest

## Must Do
- 同一 SKU 可延伸不同 Persona / Scene / Message Signal，但 Product Identity 必須固定。
- 每個 variant 要能追溯到 target signal 與 source asset。
- 優先建立真正不同的創意訊號，而不是只有換背景或裁切。

## Must Not Do
- 不得因追求素材多樣性而改變 SKU 真實外觀。
- 不得自行創造功能、促銷或不存在的商品資訊。

## Validation
需通過平台比例 / 安全區、商品一致性、訊號差異性與商用品質檢查。
