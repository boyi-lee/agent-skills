# Skill: Channel EDM

## Purpose
把已通過 Quality Review 的素材轉成 EDM 可用版位與組合。

## Input
- approved asset
- product asset
- campaign message
- edm layout spec

## Output
- hero visual
- product block visual
- supporting crop variants
- ratio / export manifest

## Must Do
- 保留商品可辨識度。
- 依 EDM 閱讀順序安排主次資訊。
- 所有加工都必須回指原始 approved asset。

## Must Not Do
- 不得修改商品身份或產生不存在的商品細節。
- 不得自行創造價格 / 優惠 / USP。

## Validation
需通過 EDM 版位、閱讀性、商品一致性與必要文字安全區檢查。
