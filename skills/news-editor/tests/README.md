# Tests

## before-after/
Store short, user-owned or synthetic examples with:
- input
- expected edit
- Fact Lock
- expected warnings

## regression/
Test failures that must not reappear:
- invented facts
- changed prices
- changed dates
- quote drift
- unsupported superlatives
- lost attribution
- headline/body mismatch

Do not store copied full third-party news articles as fixtures. Use short derived or synthetic examples and retain source URLs only for style research notes.
