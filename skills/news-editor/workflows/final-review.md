# Workflow: Final Review

## Pass 1 — factual
- no new facts
- no changed numbers
- no altered names
- no strengthened certainty
- quotations remain faithful

## Pass 2 — newsroom
- headline matches body
- lead contains the actual news
- attribution is visible
- paragraph order makes sense
- PR language is controlled

## Pass 3 — reader utility
- key dates/prices/locations are easy to find
- subheads are descriptive
- repeated information is trimmed
- article can be scanned quickly

## Pass 4 — style
If an author module is active, check structural similarity only after the first three passes.

Any conflict is resolved in favor of factual accuracy.
