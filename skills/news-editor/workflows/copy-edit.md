# Workflow: Copy Edit

1. Build Fact Lock.
2. Fix typos, punctuation, spacing, terminology, and unclear references.
3. Remove duplicate phrases.
4. Replace unnecessary PR wording with neutral wording.
5. Keep paragraph order unless comprehension requires movement.
6. Run attribution check.
7. Run numbers/dates/names check.
8. Compare edited copy to Fact Lock.
9. Return clean copy plus flagged uncertainties when requested.
