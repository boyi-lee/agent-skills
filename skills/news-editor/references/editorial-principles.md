# Editorial Principles

## Priority order

1. factual accuracy
2. attribution clarity
3. reader comprehension
4. information hierarchy
5. concision
6. style consistency
7. elegance

## Core principles

- Put the newest or most decision-relevant information early.
- One paragraph should usually carry one main idea.
- Prefer concrete nouns and verbs over promotional adjectives.
- Remove duplicate background unless repetition serves orientation.
- Separate reported fact, source claim, and writer interpretation.
- Use direct quotations only when wording itself matters.
- Preserve uncertainty.
- Avoid editorializing unless the format is explicitly commentary.
- When adapting PR material, remove unsupported superlatives and brand self-praise.

## Editing intensity

### Light copy edit
Typos, punctuation, wording, local clarity.

### Structural edit
Move paragraphs, consolidate repetition, clarify hierarchy.

### Rewrite
Rebuild headline, lead, and article flow while preserving Fact Lock.

Use the lightest level that solves the problem.
